# NoriShell 自建同步示例

Release 分别提供 `NoriShell_SelfHostSync_Server_<sync-version>.zip`（六个平台的独立 Go 可执行文件和部署说明）与可直接导入的 `NoriShell_SelfHostSync_Plugin_<sync-version>.zip`。两包使用相同的 Sync 版本，但不要求与应用版本一致。服务端只保存 Core 加密后的同步数据，不接触 Vault 密码、SSH 私钥明文或同步密钥。完整安装步骤见[中文指南](../../docs/guides/users/self-host-sync.zh-CN.md) / [English guide](../../docs/guides/users/self-host-sync.en.md)。

## 部署服务端

1. 从 服务端 ZIP 选与你服务器系统、架构相符的 `norishell-sync-server_*`。首次在终端直接运行，按提示输入监听端口、同步密码并确认；密码输入不可见。配置默认保存在当前用户的配置目录，之后从任意工作目录运行同一程序都会读取它。Linux x64 示例：

   ```bash
   ./norishell-sync-server_linux_x64
   ```

2. 默认仅监听 `127.0.0.1`。其他设备直连时，显式运行 `./norishell-sync-server_linux_x64 --listen 0.0.0.0:8787`，在插件填服务器实际 IP，例如 `192.168.1.10:8787`（自动按 HTTP 处理）；`0.0.0.0` 只是服务端绑定地址。HTTP 会明文传输服务密码、访问令牌和请求元数据，推荐使用 HTTPS，尤其是公网或不可信网络。HTTPS 可将代理转发到本机监听地址；代理需保留 `Authorization`、`If-Match`、`Idempotency-Key` 和 `X-NoriShell-*` 头，并允许最大 96 MiB 请求体。为 `/auth/login` 配置请求速率限制；不要记录认证字段或请求正文。
3. 备份整个数据目录；更换同步密码可运行 `password ... set`，已有登录会话会立即失效。服务密码由部署者配置，不能与 Vault 密码混用。服务密码只用来登录你部署的服务；同步内容仍由 NoriShell Core 端到端加密。

首次初始化后可由 Linux systemd、macOS launchd 或 Windows 任务计划程序托管服务端，让它在后台运行并随系统启动；程序本身保持前台模式。具体示例见 服务端 ZIP 内的 `README.md`。

可在插件里填完整的 HTTP 或 HTTPS 地址；纯 IP、`IP:端口` 和 `localhost` 默认按 HTTP 处理，纯域名默认按 HTTPS 处理。HTTPS IP 地址仍需要客户端信任、且包含该 IP 的有效 TLS 证书。插件不提供关闭证书验证的选项。非交互部署、自定义数据目录与代理示例见 服务端 ZIP 内的 `README.md`。

浏览器打开服务端同一地址（例如 `http://192.168.1.10:8787/`），使用同一同步服务密码登录，可查看云端数据是否存在、当前修订号、密文包大小和服务端最近写入时间。网页按浏览器语言显示中文或英文，其他语言默认中文。页面只读；服务端无法解密 SSH Host、远程桌面或密钥，因此不会展示这些内容。网页登录表单使用签名防伪令牌，兼容把上游 `Host` 改为本机地址的宝塔反向代理；更新服务端后先刷新登录页再提交。网页会话与插件 API 令牌相互隔离；HTTP 网页登录同样会明文传输密码和会话 Cookie。

## 安装与同步

1. 在 NoriShell 的插件页导入 插件 ZIP，按需授予页面与 `sshSync` 权限。
2. 打开同步页面，点击顶部“填写服务器地址”提示，在插件设置填写可访问的 HTTP 或 HTTPS 地址。再输入用户 `owner` 和服务密码登录；密码经宿主安全表单提交，插件代码不会读取密码。Core 保存会话，后续打开页面时在已解锁 Vault 下恢复登录并显示上次验证的远端列表；明确点击“刷新远端状态”才会查询服务器。会话失效或 Vault 未解锁时页面显示原因。
3. 首台设备可先检查或调整默认的全部可移植数据范围，再执行首次同步。新设备先创建或解锁本机 Vault；恢复已有设备的加密内容时，另行输入最初上传远端数据所用的 Vault 密码，本机 Vault 密码可以不同。检查远端差异和方向后再确认。
4. 当前版本只在同步页明确点击“立即同步”时执行同步。已有基线时，同一项目的双端修改默认按可信更新时间采用较新版本，删除默认采用较新删除；两者可分别改成询问。缺少可信时间或需要 Vault 解锁时，由页面引导人工处理。设备时钟偏差会影响较新版本判断。

新版 Core 对首次创建的云端数据使用稳定的插件数据标识。此前插件版本上传的密文会在完整校验后沿用原标识，因此升级插件 ZIP 不需要清空远端。新设备若没有原同步密钥，进入页面的后台刷新只提示需要用户操作；请明确点击“立即同步”，再在受保护窗口输入原设备的 Vault 密码恢复同步密钥。不要使用“远端重置”处理正常的升级。

插件导航、页面、设置和同步状态跟随 NoriShell 界面语言显示中文或英文。

同步范围只包含可移植的 SSH 主机、身份与加密凭据、RDP/VNC 远程桌面配置及其必要依赖；应用偏好和终端历史保留在本机。机器绑定的 Agent/FIDO/外部文件引用和本机自动解锁材料不会上传。对象冲突或失败会暂停同步，留待人工处理。

更多协议与运维细节见 服务端 ZIP 内的 `README.md`。本示例仅提供单用户、单数据目录服务；同一数据目录只运行一个服务端实例。
