Use only the [Plugin API reference](../plugin-api/README.en.md) from guest code. The [Core API catalog](../core-api/README.en.md) documents renderer IPC for application maintainers and is not a plugin API. The SDK and its local CLI target the stable resident ABI baseline, protocol **1.13**, with same-major forward host upgrades preserving baseline plugins; source integration and a successful ABI harness do not establish native acceptance.
