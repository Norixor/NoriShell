# NoriShell Plugin Guide

This retained URL is a directory page for the Web-ready guide collection.

- [User guides](users/README.en.md): install, update, enable, uninstall, permissions, and recovery.
- [Developer guides](developers/README.en.md): package, protocol-13 Wasm ABI, broker integration, UI, and release checks.
- [Plugin API reference](plugin-api/README.en.md): the public guest contract, its complete broker-method list, and guest-safe types.
- [Core internal API catalog](core-api/README.en.md): application IPC, explicitly not callable by plugins.

The current plugin protocol is **1.13**. Current availability and native acceptance are recorded only in [implementation status](../../README.en.md#installation-and-quick-start); native desktop, Windows, and hardware acceptance are still P19 at this checkpoint.
