# 管理插件

Plugins 页面是导入本地包、查看已安装插件、切换启用状态、升级和卸载的唯一入口。本地 ZIP 会先被复制到 Core 私有临时区，再检查受限 ZIP、manifest、平台与应用兼容性；随后才显示包内自报身份、版本、SHA-256 与申请能力。应用 UI 不保存原始选择路径。

NoriShell 不提供在线插件市场或自动更新检查。升级时，用户为同一插件明确选择更高版本的本地 ZIP，并复用同一验证和原子安装路径。每次导入新的包版本都必须重新审阅权限；已安装版本的授权和主机范围不会继承。禁用会停止新的 guest 工作并移除其贡献。卸载按该包支持的方式让用户选择保留或删除插件私有的非秘密数据。

包校验与原生验收是两件事。本检查点的 native desktop、Windows 与 hardware 验收仍属 P19；package preview、导入校验成功或已安装状态都不能关闭该门槛。当前限制和验收证据见[实施状态](../../../README.md#安装与快速开始)；批准前请阅读[权限与恢复](plugin-safety.zh-CN.md)。
