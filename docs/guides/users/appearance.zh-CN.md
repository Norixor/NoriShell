# 主题与外观

1. 在“插件”页导入主题 ZIP 并启用；安装本身不会切换界面。示例包为青苔和绛夜 1.1.0、暖砂 1.0.0，构建说明见[主题开发指南](../developers/themes.zh-CN.md)。
2. 打开“设置 → 外观”，所有主题在同一列表显示并标注浅色或深色。选择卡片先预览，保存时切换到该主题对应模式。外观模式下拉框即时保存；跟随系统使用最近保存的浅色和深色方案。
3. 调整颜色、字体、字号、圆角、边框、密度和阴影，在组件与列表预览中检查效果。编辑先保留为草稿，点击“保存更改”才应用到普通界面；“取消更改”恢复当前已保存设置。
4. “恢复此主题默认”仅清除所选主题的自定义草稿，保存后生效。颜色对比度不足时不能保存，请同时检查文字和背景。

“导入配置”先载入草稿；“导出已保存配置”保存当前已应用配置，而不是尚未保存的草稿。配置文件不包含主题插件本身，换设备后需另外安装对应 ZIP。已有插件缺失、禁用、损坏或进入安全模式时会使用同模式内置主题，原自定义保留；更新后的不兼容覆盖也保留，但暂不应用。

终端在“终端偏好”中独立管理。选择跟随应用时可使用主题包提供的终端配色；固定方案和自定义终端配色不会被应用主题覆盖。切换配色不会建立、重连或结束终端会话。

安全确认、密码与权限对话框保持内置外观，原生窗口控件和系统文件选择器受系统限制。普通插件面板可跟随主题；自行绘制的隔离网页需要插件提供支持。当前平台验收状态见[实施状态](../../../README.zh-CN.md#安装与快速开始)。

青苔和绛夜沿用原澄明、午夜的主题标识。本地 ZIP 不能凭自报作者直接更新不同包：替换时先卸载旧主题并保留数据，再导入、启用新包。原自定义仍保留，需完整新配色时使用“恢复此主题默认”并保存。
